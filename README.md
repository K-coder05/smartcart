# SmartCart
## From cooked to cooking

**Functional Prototype — 45%**
● All major workflows and core features are fully implemented.
● Includes at least 5 meaningfully different pages or interface states.
● Supports account creation, login, logout, and user-specific data.
● Uses real input, output, and persistent data.
● Includes clear navigation, validation, loading, confirmation, error, and empty states.
● Deployed prototype is accessible and works in the intended browsers or devices.

**Basic and Stress Testing — 25%**
● At least 10 feature tests are documented.
● Each test includes the expected result, actual result, and any fix or iteration.
● Includes both successful and unsuccessful tests.
● At least 5 stress or edge-case tests are documented.
● Testing results lead to clear improvements to the prototype.

**User Manual — 10%**
● Clearly explains the project, intended users, and prototype setup.
● Includes device, browser, and account-creation instructions.
● Provides step-by-step instructions for every major feature.
● Describes expected results, known limitations, and troubleshooting.
● Allows someone unfamiliar with the project to evaluate it without assistance.

**Updated Development Plan — 10%**
● Updates the existing Milestone 3 plan rather than creating a separate plan.
● Clearly marks completed, remaining, and newly discovered tasks.
● Assigns responsibilities and realistic deadlines.
● Identifies blockers and goals for the next week.

**Implementation Process and AI-Use Reporting — 10%**
● GitHub history shows regular, meaningful progress.
● Contributions and responsibilities across team members are clear.
● The [AI coding tool-use form](https://docs.google.com/forms/d/e/1FAIpQLScikyTkE543_XZIOiZ9j59Od63aDIVDe-mY7-Ji_v_Pq67p-A/viewform) is completed accurately.
