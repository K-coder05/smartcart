# SmartCart

**From cooked to cooking.** SmartCart is a mobile-first web app that suggests recipes based on what you're in the mood for, lets you save favorites, and builds a grocery list.

## Features
- Sign up / log in (Firebase Authentication)
- Recipe suggestions generated by Google Gemini, streamed so results appear as they're produced
- Recipe photos fetched from the lead image of the best-matching Wikipedia article (cached in `localStorage`)
- Saved recipes and a grocery list

## Tech stack
- Vanilla HTML/CSS/JS (`index.html`, `css/`, `js/app.js`)
- Firebase (auth and data)
- Gemini API (`gemini-3.1-flash-lite`), proxied through a serverless endpoint so the API key stays server-side
- Cloudflare Workers/Pages for hosting

## Project structure
```
index.html            App markup
css/style.css         Styles
js/app.js             Client logic (auth, recipe generation, images, saved/grocery)
functions/api/        POST /api/generate: streaming Gemini proxy
src/worker.js         Workers entry point; routes /api/generate, static assets served first
public/images/        Mascot and logo assets
design-process/       Design process write-up
wrangler.jsonc        Cloudflare configuration
```

## Running locally
```bash
npm install
npx wrangler dev
```
Create a `.dev.vars` file with your Gemini key:
```
GEMINI_API_KEY=your-key-here
```

## Deployment
Hosted on Cloudflare (migrated from GitHub Pages). Set `GEMINI_API_KEY` as a secret in the Cloudflare project settings, then deploy with `npx wrangler deploy` or via the connected Git repo.
